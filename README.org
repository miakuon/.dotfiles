#+title: Mia's dotfiles

* What are dotfiles?
Dotfiles are the customization files that are used to personalize your system. You can tell that a file is a dotfile because the name of the file will begin with a period – a dot! The period at the beginning of a filename or directory name indicates that it is a hidden file or directory. This repository contains my personal dotfiles. They are stored here for convenience so that I may quickly access them on new machines or new installs.  Also, others may find some of my configurations helpful in customizing their own dotfiles.

* How to use it
** Setup
1. Clone this repository
   
   : git clone https://github.com/miakuon/.dotfiles.git ~/.dotfiles
   
2. Make sure =stow= is installed
   
   : sudo pacman -S stow
   
3. Make symlinks
   
   : cd ~/.dotfiles
   : stow --adopt .
   
** Add new configs
1. Commit or stash git changes
   
2. Copy new files 
   
3. Update symlinks
   =TIP=: Update ~.stow-local-ignore~ if you don't want to make symlinks for some files 
   
   #+begin_src bash
   cd ~/.dotfiles
   stow --adopt .
   #+end_src   
   
4. Apply git changes
